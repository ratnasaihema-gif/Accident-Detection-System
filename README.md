# 🚗 Smart Accident Detection System

## 📌 Overview
An embedded system that detects vehicle accidents using an MPU6050 sensor and automatically sends alerts through a GSM module.

## 🎯 Objectives
- Detect accidents automatically
- Improve emergency response
- Send alert messages instantly

## ✨ Features
- Accident detection
- Motion sensing
- GSM SMS alerts
- Real-time monitoring

## 🛠️ Technologies Used
- STM32
- Embedded C/C++
- MPU6050
- GSM Module
- STM32CubeIDE

## 🔧 Hardware Components
- STM32 Development Board
- MPU6050
- GSM Module
- Power Supply
